# Mi receta

## Descripción
Este repositorio contiene mi receta de cocina, realizada como práctica para aprender a utilizar Git y GitHub.

En él se guardan los ingredientes, las cantidades y los pasos necesarios para preparar la receta.

## Contenido del repositorio
- Título de la receta.
- Lista de ingredientes.
- Cantidades necesarias.
- Preparación paso a paso.
- Archivos adicionales de la receta.
